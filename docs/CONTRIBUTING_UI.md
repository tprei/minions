# Contributing UI changes

The UI is a React 18 + Vite 5 + TS PWA under `pwa/`. See [PWA_DEV.md](./PWA_DEV.md) for the
local dev workflow, layout, testing, and deploy notes.

The vanilla-JS PWA that this doc previously covered was removed in the cutover series
slice-pwa-s0 through slice-pwa-s5; consult git history before that for the legacy structure.
